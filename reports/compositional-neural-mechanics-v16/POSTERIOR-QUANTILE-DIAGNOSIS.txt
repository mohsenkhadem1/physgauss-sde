Bounded posthoc diagnosis: no new mechanics calls; original posterior unchanged

Conclusion
No correctness bug was identified in the positive conditional-CDF implementation.
The observed VF failure is consistent with inadequate ratio-node resolution for
quantiles, despite excellent low-order moments. V remains numerically qualified;
VF remains unqualified. This diagnostic does not replace either conclusion.

Derivation
Let s=log bulk scale, r_j=log K_j-s, and c_j=r_j-log(500).
At fixed r, the log conditional density, up to an s-independent constant, is
 -.5*[s^2+(s+c_L)^2+(s+c_R)^2] -.5*A*(exp(s)-B/A)^2.
Its derivative is -3s-c_L-c_R-A exp(2s)+B exp(s). The implemented mode-search
split points solve the derivative's extrema: 2A y^2-B y+3=0, y=exp(s).
The discriminant B^2-24A and roots in the source are correct. The omitted C
and B^2/A terms are constant at fixed r and cancel in the normalized CDF.
The interval for x_j=s+r_j correctly uses F_s(t-r_j | r). Mixture weights
retain the full position/wrench likelihood and prior. Scalar normalizers agree
with 2049-point Simpson integration at approximately 1.5e-11 relative error.
Thus this mass approximation cannot explain the much larger endpoint shift.

The ratio integral is still a finite Gauss-Hermite mixture. For VF, its narrow
conditional scale kernels make F_s(t-r_j | r) vary sharply across r. Polynomial
moments can converge much sooner than this near-indicator integrand. Increasing
proposal width with unchanged order doubles central node spacing and reduces
useful node density; it is not itself a more accurate quantile calculation.

Recommended next bounded strategy (not executed)

   Fit forward vectors, not posterior weights or interval endpoints. Preserve
   exact common-scale exp(s) wrench law, exact bounded prior and positive density.
2. Compute an independent high-resolution/adaptive continuous ratio integral
   using degree3 and degree4 response approximations; compare all moments,
   evidence and CDF values/endpoints with independently tightened integration.
   For logK quantiles, integrate coordinates x_j=s+r_j with the CDF boundary as
   an integration limit rather than asking sparse fixed-r nodes to approximate
   a sharp indicator. This removes the particular grid-mixture artifact.
3. Quantify likelihood sensitivity using |delta log L| <= ||residual||*||error||
   + .5||error||^2, separately for position and exp(s)-scaled wrench over s[-1,1].
   A uniform log-density error epsilon would imply normalized density ratios
   bounded by exp(+-2epsilon); finite cached validation alone does NOT establish
   that bound. Check tails separately, rather than invoking Gaussian prior tails
   as posterior-tail bounds. Extend/check the approximation outside the core or
   retain a separately converged tail integral.
4. Before accepting an interpolated reference, use independent off-grid exact
   solves targeted at the mass/CDF-transition region and tail boundaries, plus
   approximation-order and integration-tolerance refinement. Report this as an
   independently validated surrogate reference if it passes, never silently
   replacing the original exact-node study. No new solves were run here.

An exact no-surrogate alternative is adaptive/quantile-aligned cubature in the
ratio variables with cached exact solves; it requires some new nodes. Combining
old grids or replacing intervals by Gaussian mean +/-1.645SD does not establish
convergence. Arbitrary smoothing of the discrete ratio mixture is inappropriate.
