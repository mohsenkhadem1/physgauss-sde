Development full-continuous pilot input contract (written while fits run)

Plan is saved before sample_scene is called. Each CPU worker deterministically draws the same two declared scenes then uses its assigned scene. Truth is passed to the separate teacher generator and post-fit evaluation only. The JointMAP builder receives GeometrySpec, three categorical candidates, noisy observations and optional frozen laws; no scene dictionary is passed to its constructor. All15fit values start at neutral_parameters(), independent priors; active indices cover all15. Each observation dictionary is explicitly restricted to pose, points, displacement. No force or torque is observed. Known gravity/density are external public settings.

Categorical conditioning remains substantial: both selected cells are MR bulk, with different interface families and heterogeneity patterns. This is not a two-bulk-family unknown-categorical inverse experiment. World0/1 are two development examples, not independent benchmark datasets. Targets use analytic n2 and predictions n2, so numerical/model-discrepancy conclusions remain limited. Cases and heldcommands are retained regardless of outcome.

Timeout handling: dedicated worker process alarms cap each fit, while JointMAP retains best complete objective evaluation on TimeoutError. A parent shared3600s deadline terminates owned process groups. Incomplete or optimizer-failed fits may still produce diagnostic held-out forecasts; never label these converged. Held-out evaluation is outside the fit objective. Source hashes bind the recursive local dependency closure and both checkpoints; source mismatch is recorded, not repaired silently.
