FIGURE 1 v01 - HELD-OUT CAMERA 0 RENDERING (reported beside physics)
Protocol (protocol_fig1.json "rendering"): camera 0 (never used for fitting) foreground PSNR, reported
beside physics; appearance per method's own native renderer.
Code: scripts/fig1_v01/render_cam0.py (refs | gic | raster | score). Scores: reports/fig1-v01/render-scores.json
(summary_over_worlds, rows per world incl. full-frame PSNR and physics RMS, per_frame). Renders, references,
appearance models and logs: runs/fig1-v01/render-cam0/ (local, git-ignored).
Inputs: only sealed predictions. fig1_score.verify() is called for S1/S2/S3 (all hashes match) before any
render and again at scoring; every rendered file is looked up through its sealed() map. No sealed source was
missing (skipped_unsealed is empty).

METRIC
Reference: truth episode (S1 D2c, S2 block D2, S3 D3) rendered on camera 0 by the trial's own rasteriser
(scripts/stem_trial_v01/render.py; same camera, texture, shading as every fitting scene), written fresh to
runs/fig1-v01/render-cam0/scenes/{EP}-{W}/data/r_0_*.png and read from r_ files (m_ here are byte copies
of r_; no PAC-NeRF preprocessing ever touched these folders).
Foreground mask: reference pixels that are not pure white (255,255,255) - GIC reader's rule, as round 2.
fg PSNR = -10 log10 of MSE pooled over the mask over frames 1..end (frame 0 = shared given rest state),
RGB in [0,1]. Full-frame PSNR also stored. GIC renders on black (its training convention), so its
reference is composited onto black; PAC-NeRF native and the rasteriser render on white and are compared
with the white reference. The mask is the TRUE silhouette only: pixels a prediction puts outside it are
not penalised by fg PSNR (full-frame PSNR does see them).
Means over worlds are means of per-world dB values.

RENDERERS
SH  primary: shared GIC appearance. One fixed appearance per object = GIC's own fixed-particle Gaussians
    (its native appearance stage, train_gs_with_fixed_pcd, 40k it) trained on cameras 1-10 of its D0
    (initial-footage) fit. Stem (S1, S3): the round-2 model runs/stem-trial-v01/gic/D0 (trained 2026-11-09,
    reused, not retrained). Block (S2): trained here, one per world on that world's D0 footage
    (render-cam0/gic-appearance/D0-B*), driven by GIC's native simulator replay of D0.
    Every method's predicted motion drives the same Gaussians -> PSNR differences isolate motion.
GN  GIC native, refit: GIC's D1 forecast through its own D1-refit fixed-particle Gaussians (stem: round-2
    models gic/D1-W*; block: trained here, render-cam0/gic-appearance/D1-B*), with true motion through the
    same model as its own ceiling. GIC's D0 forecast natively = the SH row (same model, same particles,
    identity transfer).
PN  PAC-NeRF native: the 'rgb' array saved in each sealed PAC forecast (render_sequence on rays of camera 0
    of its fitting scene; camera 0 is identical in every scene; silhouette IoU vs truth camera 0 = 0.93,
    vs other cameras <= 0.81).
RA  secondary: true-texture rasteriser = the reference renderer itself with the TRUE rest mesh and texture
    (privileged appearance; ceiling is exact, i.e. infinite PSNR), driven by each method's motion
    transferred to the truth mesh nodes. Most motion-sensitive; not a native renderer of anyone.
M-PhyGs, PhysTwin, ours (RGB): no native renderer in adapter (SH and RA rows only).
S2 fitted spatially varying FEM (control): NOT rendered - its sealed output is the 27 top-surface probe
    displacements only; there is no field or particle set to drive an appearance, and re-simulating it
    from its fitted parameters after truth opened would not be a sealed prediction.

MOTION TRANSFER (same rule for all methods)
Target points (Gaussian rest centres for SH/GN, truth mesh nodes for RA) get the inverse-distance-squared
weighted mean displacement of the K=4 nearest source rest points; source rest = frame-0 particles
(GIC/PAC/M-PhyGs/PhysTwin: xyz[f]-xyz[0]) or FE nodes (ours: X, D0/D0pD1 or U). Identity when the target
points are the source's own particles (GIC forecast through its own model). True motion is given both
through the same IDW rule and by exact T10 FE interpolation (round-2 rule); they agree to <=0.02 dB, so
IDW transfer itself costs nothing measurable for a dense source.
S3: the striker sphere is NOT rendered in the reference or any prediction; the existing pipeline never
renders it (no D3 scene existed; render_scene/write_scene draw only the body).

READING
- Stem (S1, S3): with one shared appearance, ours after calibration reaches the appearance ceiling in every
  world (21.62 vs 21.64; 21.75 vs 21.70), the only predictor that does; baselines lose 1.3-2.6 dB (S1) and 0.7-3.5 dB (S3).
  The rasteriser ranks the same way with far more spread (ours D1 30.5/32.8 dB, best baseline 22.0/22.4).
- Block (S2): the shared GIC appearance cannot discriminate motion - all predictors lie within 0.4 dB of the
  20.72 dB ceiling (GIC D0 nominally 0.01 dB above it) because block displacements are a few mm while the
  appearance error is ~20 dB. The rasteriser does discriminate and orders as physics (ours 34.7, M-PhyGs
  29.8/28.2, PhysTwin, PAC, GIC 23.7). Treat S2 SH as uninformative, not as a tie in physics.
- PSNR compresses physics: rankings mostly follow RMS, but not exactly (e.g. S1 PAC-NeRF, worst in RMS,
  is mid-pack in SH because it is good at W2000).
- PAC-NeRF native renders are appearance-limited (frame-0 fg PSNR ~14 dB: dark, blurred texture), so its
  native numbers measure its appearance model, not its motion.

DEVIATIONS / LIMITATIONS
1. Protocol says "appearance per method's own native renderer". Only GIC and PAC-NeRF have one; the
   primary metric is therefore the shared-appearance PSNR (round-2 design), with native rows where they
   exist. M-PhyGs and PhysTwin adapters carry no renderer; ours has none (no native renderer in adapter).
2. Block GIC appearance models (D0 and D1 per world, 6 models, ~9 min each) did not exist and were trained
   here with GIC's own fixed-particle stage on copies of the GIC runs (render-cam0/gic-appearance/; the
   original runs/fig1-v01/block/gic dirs are untouched), driven by GIC native-simulator replays of D0/D1
   (render-cam0/gic-fit/fit-*.npz, generated here with the labelled force adapter). They were trained after
   the D2 truth existed, but they see only D0/D1 footage from cameras 1-10, so no held-out information.
3. Image provenance: PAC-NeRF's preprocessing overwrote data/m_*.png (matted) in place in the shared scene
   folders, and GIC's reader trains on m_. A first block-appearance attempt read those matted m_ images; it
   was stopped before producing any render and deleted. The block appearances used here were trained on
   clean copies (render-cam0/clean-scenes/{D0,D1}-B*: all_data.json, r_ images, m_ := r_, GIC's
   points3d.ply); render_cam0.py asserts m_ == r_ before any appearance training. The stem appearances
   (trained 2026-11-09 ~10:30) predate any PAC-NeRF run on the stem scenes (first 14:03), and the original
   GIC block fits (2026-11-09 14:37-20:00) predate the first PAC block run (23:17), so they saw unmatted
   images. All references are read from freshly rendered r_ files.
4. ours S2: the sealed field file has identical D0 and D0pD1 fields (also identical physics, 0.33 mm), so
   both stages render identically. Not a rendering artefact; flagged for checking upstream.
5. Small exceedances of the ceiling (ours S3 D1 +0.05 dB, GIC S2 D0 +0.01 dB) are within appearance noise:
   the Gaussians are fit to GIC's own imperfect replay, not to truth motion.
6. IDW transfer: sparse sources (PhysTwin 3-6k particles) and bloated ones (PAC-NeRF's cloud extends
   ~5 cm past the body) are resampled by nearest neighbours; any transfer loss is charged to the method.
   For the dense truth field IDW and FE interpolation agree to 0.02 dB.
7. Striker sphere not drawn (see above); S3 rendering scores stem motion only.
8. GIC's refit (D1) appearance absorbed its own refit motion errors; its native row is shown with its own
   ceiling and is not comparable across methods - SH is the comparison.
