POSITIONING
The defensible contribution is a controlled spatial material/interaction
identification and measurement-selection study. FEM is its forward model.
Gaussian force elimination, joint Bayesian system identification, Gaussian
task-frame interactions, and prediction-oriented experimental design all have
precedent. The exact finite-hypothesis reference should be presented as a
reference algorithm, not arbitrary continuous-field recovery from raw video.

BEFORE FINAL TEST RELEASE, RECORD THESE NUMERICAL DETAILS
- Exact dictionary values and prior masses, continuous stress distribution,
  independent development/test seeds and case counts; material/load prior units.
- Camera matrices, visible/hidden point sets, all observed times and noise.
- Acquisition candidates, scalar versus image cost, reset protocol, probe N,
  number of actions, and fixed-sequence selection exclusively on development.
- Exact fixed target coordinates/times/known changed loads and their weighting.
  If original unknown-load motion and known new-load response are combined,
  disclose the weighting and report each separately. Otherwise target choice
  can predetermine which modality wins.
- Separate information-gain action ranking from direct uncertainty/confidence;
  MC selection counts and high-sample ranking/expected-risk audits.
- Mesh refinement at sampled actual parameter regimes, not only one nominal
  case; nonrigid amplitude, maximum strain and support discretization changes.
- Dictionary refinement or independent continuous posterior diagnostic before
  interpreting off-grid undercoverage as merely a statistical-model issue.
- Distinguish marginal MAP and profiled joint MAP: H(theta) varies, so their
  determinant-volume correction varies. They are different estimators, not an
  exact-identity test. Add determinant-corrected profile identity as the control.
- Fixed force prior can anchor absolute stiffness statistically. The likelihood
  scale symmetry must be tested separately from posterior/prior preferences.
  Test more than one declared force prior scale, preserving all results.
- Temporal force observations are correlated; updates must retain full force
  covariance. Equal-tail coordinate intervals are not whole-field coverage.
- Signed Gaussian amplitudes allow pulling. Call unknown fields traction/load
  hypotheses; calibrated reset probes may be compressive but do not establish
  unilateral contact inference or nonpenetration.

CODE REVIEW
mechanics.py uses positive Gaussian bottom support without hidden rigid pins.
Its support stiffness is a lumped nodal diagonal of integrated Gaussian gate
weights, not a consistent integral of w*N^T*N. This is a declared finite model;
refinement should include this approximation. Fixed two material kernels and
shared x footprint for top/side modes must be exposed in figure labels.

inference.py includes hypothesis-dependent covariance determinants, retains
paired force/hypothesis samples, uses total covariance, and has useful
batch/sequential and action-order identities. expected_risk_mc samples only
predictive observations and risks_after_values leaves state unchanged.
Quantiles handle point-mass components explicitly. Numerical exactness remains
conditional on the finite dictionary and affine observation map.

NEURAL MARGINALIZATION REVIEW AND UPGRADE CHOICE
src/physgauss/neural_marginal.py already demonstrates exact conditional Gaussian
load elimination even with nonlinear mechanics and state-dependent discrepancy.
Q(z) is evaluated at the preceding velocity/position, does not depend on load
coefficients after conditioning on the path, and is block diagonal across kicks.
The code differentiates changing logdetQ and logdetA; it includes causal path
Jacobian terms. The covariance-information matrix is a local approximation,
not an exact nonlinear posterior. Its tests and old results do not qualify a
new heterogeneous force-location model automatically. Current torch.eye calls
often omit device, so a direct GPU transplant requires a device audit.

RECOMMENDED NEXT UPGRADE AFTER THE FINITE REFERENCE WORKS
Prefer continuous five-parameter tempered SMC over a new nonlinear RGB loop.
Keep the same linear 3D forward/observation model and exactly integrate the 16
load coefficients for every particle. Infer continuous logE, contrast, support
x, logK and load x. Use bounded physical priors, correct transformations,
adaptive temperature ESS, MH rejuvenation, independent seeds and count doubling.
Validate on low-dimensional slices and finite-dictionary limiting cases; compare
CDFs, predictive mean/std, force moments, logZ and particle diversity across runs.
Particle ESS immediately after resampling is not convergence evidence.

Practical staging within remaining12h: first profile128/512 particles on64-node
or smaller mechanics; cache immutable tensors, use GPU Cholesky in bounded chunks.
Then run4 independent seeds at512/2048 particles on a few declared development
cases, and only increase cohort if comparison stabilizes. Acquisition can start
with reweighting existing posterior particles, but post-measurement collapse
requires re-running/rejuvenating posterior rather than claiming an exact update.
This is an implementation estimate, not a measured runtime guarantee. Full
nonlinear trajectory inference would add thousands of latent states and revive
the old local-posterior/rendering bottleneck; defer until continuous field
reference and informative excitation are established.
