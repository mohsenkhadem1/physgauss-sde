MODEL-CLASS SELECTOR — INDEPENDENT DECISION AUDIT
2026-10-30; proposal reviewed after148case campaign/feasibility decisions.

DECISION
Conditionally approve ONE bounded, fully predeclared exploratory comparison on all
148cases. This is a useful model-selection question: can an observed-prefix rule
choose between rigid motion and alternative physical models without future truth?
Do not frame it as curing zebra or rescuing the paper. Preserve current148primary
predictions/results unchanged and label every new result post-audit exploratory.
There is no untouched solid PhysTwin catalog left; no independent claim transfers.

PHYSICAL SCOPE
Refitting field-free FEM is correct; merely zeroing a coefficient after fitting
would confound changed equations with parameters optimized for the other model.
However field=False in existing FEM disables ONLY the Gaussian world potential.
Gravity, floor response and localized tangential compliant-support energy remain.
Therefore this is a Gaussian-potential ablation, NOT removal of all world forces,
contact/support inference or proof that the current jump is caused by that field.
Rigid motion is a legitimate simpler model for predominantly rigid observations.
It does not identify an object as intrinsically rigid under all future loads.
The selector forecasts under supplied tool trajectories; it does not identify
unseen force families, friction laws, material truth or calibrated uncertainty.

REQUIRED FIXED DESIGN BEFORE ANY NEW FULL-SUFFIX SCORING
1. Archive candidate definitions, source hashes, bounds, fits100iterations/36frames,
   same meshing/observations, fixed70/30observed-prefix split and2%gain/tie rule.
   Candidate set: frozen current-field pipeline, newly refitted Gaussian-field-off
   pipeline, and matched prefix-calibrated rigid+scene policy. All inherit same
   position controls and geometry, friction/state policy and output topology audit.
2. Guard/contact are PART OF the evaluated candidate. Compute validation errors
   after those operations, including their altered geometry/initial velocity.
   Do not select raw residual accuracy and then silently count repaired accuracy.
   Define whether seven adapter options are fixed within each class or selected
   jointly with class; record every option. Any nested use of same validation is
   ordinary adaptive selection, not an additional independent validation estimate.
3. Current-class baseline must be evaluated using the same shortened-prefix,
   full downstream processing and masks. The2%threshold is relative to that
   candidate's validation error, not its full-prefix fit error or original suffix.
   Strict tie/no2%gain retains current guarded class. Do not use future failures
   to substitute a better candidate after selection.
4. Every class's shortened-prefix fit, grasp calibration, rigid initialization,
   support parameters and state classifier use only that earlier segment. The
   full observed prefix supplies validation targets ONLY until the class is
   selected; refit/recalibrate selected class on full prefix afterward. Existing
   frozen full fits may be reused only for the identical current-class recipe.
5. Reject a validation candidate uniformly on nonfinite outputs, missing required
   frames or topology-invalid frames; do not average only its valid intervals.
   Declare behavior if ALL validation candidates fail (retain explicit failure
   or predeclared rigid fallback labelled as such). Do not claim validation passed.
6. Preserve optimizer convergence flags. Best valid checkpoints from abnormal or
   budget-limited optimization are predictions, not certified fitted solutions.
   Use the same timeout/continuation policy for both full and validation fits.
7. The primary full-suffix error is never an input to class/adapter selection,
   thresholds, restart order, stopping or fallback. Test future-channel poisoning
   for the entire selection pipeline and trace all per-case inputs and decisions.

COMPARABILITY / REPORTING
Report current guarded baseline, field-off standalone, rigid+scene standalone,
and selected mixture for every case; include selected class, validation scores,
validity/fit flags and original suffix metrics. Use identical material/force-label
restrictions. Extra fitting/selection is extra complexity even if speed is not
currently the objective; report fitting budget and parameter/candidate counts.
Do not compare a seven-option new selector with a weakened unmatched old method.
An oracle hindsight best-class score, if computed, is analysis only and clearly
labelled unattainable; it cannot count as the achieved result or guide another
round of tuning. No per-case manual switches. Keep all oldphase labels visible.

ACCEPTANCE / STOPPING CRITERIA
Engineering acceptance: all148members accounted for; source freezes preserved;
selection independently replayable from prefix inputs; finite/topology-valid final
outputs or explicit failed cases; original metrics and new secondary scores retained.
Scientific evidence: report whether selection improves the paired dataset mean
against currentguard AND rigid+scene, worst cases and shape metrics; if it does
not, retain the negative result. No requirement to declare overall success just
because some cases improve. A lower mean with worse tails or shape must be stated.
Predeclare only one selection recipe. Do not alter thresholds/classes after its
full-suffix outcomes. If numerical validation fails, fix only demonstrated code/
solver defects with explicit amendments, not a parameter search on target errors.
