CROSS-METHOD DESIGN AUDIT v02
2026-11-07. Independent scientific/evaluation design review.

SCOPE CORRECTION
The preceding gap-first campaign did NOT satisfy the requested native cross-method comparison. It established a ReconPhys native forward ambiguity, a small named-native predictor diagnostic, an analytic stem reference and a nonlinear contact reference. The failed spring-core adapter is not a native PhysTwin result. Its successes must not be relabeled as results against PhysConvex, MASIV, M-PhyGs, PhysTwin, GIC or PAC-NeRF.

Requested roster: PhysConvex, MASIV, M-PhyGs, PhysTwin, ReconPhys, and GIC/PAC-NeRF evaluated on compatible PhysGaia benchmark cases. PhysGaia is the requested benchmark role, not an additional method to rank. Exact official names, versions, available data, licenses and native capabilities require the separate source/capability audit. No capability is assumed from a method's title. Native support is a qualification gate, not a negative accuracy result.

MINIMAL FAIR STUDY
Do not demand an artificial universal input/solver interface. Use two clearly separated tracks:
A. Native reproduction: each official method on its released supported scenes, inputs, control types and metric definitions. Reproduce one predeclared standard example before any novel comparison. This verifies implementation, not comparative generalization.
B. Paired evidence/interaction comparison: groups of methods sharing a verified supported task receive identical observation content, calibration inputs, initial state and held-out targets. Use the intersection of supported capabilities, with distinct strata for richer depth/masks/geometry versus RGB-only inputs. A supplied-geometry diagnostic is permissible but must not be advertised as an end-to-end raw-video advantage.

Smallest meaningful primary cohort per compatible task group: three predeclared geometries, each with two physical worlds and two changed-interaction specifications, with all world/task outcomes retained. Parameter worlds must be selected from development identifiability checks before scoring, not from images where a competitor looks worst. This is an initial controlled comparison (six worlds, twelve world/task outcomes), not a large generalization benchmark. Add five or more noise repeats only for sensor uncertainty; they do not create additional objects. If only one officially released compatible case exists, publish a case study, not a benchmark win.

For each world, define three separate reset episodes:
D0: passive or initial controlled interaction used for inference. Conditioning prefix t<=T0 and available cameras are identical within a comparison stratum. Reserve later frames and recorded cameras from D0 for quantitative render/motion generalization. No future frame may enter tracking, segmentation tuning, geometry fusion, camera fitting, appearance adaptation, early stopping or model selection unless explicitly supplied equally as input.
D1: one corrective experiment selected from a frozen native-supported menu using only D0 and model predictions. For a view, acquire a previously unavailable recorded camera at a declared time while retaining the same physical episode; for an interaction, reset and apply a declared position or force control. D1 observations become fitting evidence for every refittable baseline and our model.
D2: a second, different held-out interaction with known specification but response hidden until predictions and risks are sealed. D2 must not be D1's continuation, a rephrased calibration action, or a parameter-fit target. It may change direction/location/magnitude only within the native supported interface. Measure actual response and rendering on synchronized reference cameras. Keep all rollouts including failed ones.

POSITION VERSUS FORCE
Position control supplies trajectory, collision geometry and controller settings; contact forces remain outputs. Do not insert ground-truth reaction forces into inverse fitting or label prescribed positions as known applied force. Force control supplies force vector/distribution/application frame and force units; motion is output. A per-particle body force, a local traction and a rigid-tool contact are different interventions and must be named. An intervention can be common only if the native models implement the same physical control and geometry. Any new control adapter must preserve the native force/integration/rendering code, have independent parity tests and a visible label. Otherwise report it separately as an adapter diagnostic.

WHAT IS FROZEN BEFORE OUTCOMES
1. Source/weight/data hashes, supported-case inventory and qualification exclusions.
2. Input modalities, units, coordinate transforms, cameras, T0, D1 menu, D2 specification, sensor-noise model, tolerance and target metric, training budgets and restart policy.
3. Point predictions qhat_j(D0,D2), risk scores, candidate D1 utilities, selected D1, and initial render/motion predictions.
4. After D1, updated qhat_j(D0+D1,D2), risk scores and rendering predictions, before opening D2 truth.
Store separate hashed manifests and prediction archives. Outcome scoring must read immutable predictions; it must not invoke training or select seeds/checkpoints. Prospective candidate response banks may be used to compute risk, but the selected world's true target cannot enter posterior weights, acquisition or fit selection. Sealing already computed historical outcomes is not a prospective experiment: declare any such test posthoc.

RISK IS ATTACHED TO A NAMED POINT PREDICTION
Use r_j=P(ell(q(theta,D2),qhat_j)>delta | D), with an explicitly declared posterior/reference family. Primary ell can be point-Euclidean trajectory RMS for geometry, or a declared task failure such as final support loss. Do not mix this with scalar-coordinate RMS; distinguish mean per-case RMS from pooled RMSE. When assessing an external native predictor, its own qhat_j is the center of the risk event. An exact Bayesian-reference posterior does not make that native predictor Bayesian. Its risk can be high even when the reference posterior mean is accurate.

Retain two controls: unchanged frozen native prediction after D1 (tests risk monitoring), and native same-evidence refit where the official pipeline supports refitting. If a feedforward model cannot consume correction without a new architecture, label the update unsupported; do not replace its output with reference MAP and call that an improved native network. Reference MAP/mean with identical evidence are separate named baselines. Our own improvement must be shown against competent same-evidence refitting, not only a deliberately frozen competitor.

The reference family must contain both successful and failing native predictions on fresh cases to establish useful risk discrimination. A cohort where every native result fails and every risk=1 is a valid failure warning but not calibration/discrimination evidence. Report Brier, reliability bins with counts, failure rates at predeclared risk thresholds, and risk-coverage with uncertainty. Zero observed failures is not zero true risk. Include a declared misspecification stress (e.g. numerical/contact family omitted) separately from matched-model calibration. A mixture that includes the truth solver by construction is a conditional positive control, not arbitrary model robustness.

PAIRED METRICS
Rendering: PSNR/SSIM/LPIPS at identical held-out recorded frames/cameras, identical radiometry, image dimensions and background. Report full image and fixed reference-foreground/union masks with definitions. Specify pooled-MSE PSNR versus mean per-frame PSNR. Report conditioning fit too, to distinguish poor reconstruction from physical explanation ambiguity. Novel unrecorded camera paths are qualitative only unless the simulator supplies independent reference renders. Renderer changes can change image quality independently of mechanics; preserve each native appearance checkpoint for initial physics-only diagnostics and disclose supplied appearance.
Physics: held-out D2 trajectory point RMS with correspondence qualification, silhouette/depth or image tracks where 3D truth is unavailable; task failure; reaction force RMS when force truth exists; penetration and minimum deformation Jacobian where meaningful for the native representation; conservation residual only when known work, damping/contact dissipation and discretization are accounted for. Do not rank physical sanity using representation-specific diagnostics a competitor cannot compute. No absolute material-error claim from real videos without measured material truth.
Primary paired contrast: before versus after D1 on the same D2 for each method; then our versus same-evidence native prediction. Show rendering delta and physical delta side by side. One can improve while the other does not. Include all cases, medians and tails; not only selected screenshots. Figures use identical cameras/scales/times/color limits and declared zoom regions, with failure examples retained.
Acquisition controls: every fixed action in the small menu, random fixed-budget action, and a strong cost-aware moment-risk baseline if proceeding is allowed. Identical costs and evidence. A fixed-budget contact experiment cannot support a proceed-versus-acquire claim. Do not claim advantage over the best fixed action unless the paired evidence supports it.
Uncertainty: cluster comparisons by physical object/world and preserve paired tasks/noise repeats. For a six-world initial cohort report individual points and descriptive intervals, not strong population claims. Fix seeds and confidence interval procedure in advance.

EXECUTABLE PASS/FAIL GATES
G0 inventory: manifest entry for every requested method, official source/commit/weights and native task support; unavailable remains explicitly untested.
G1 clean native smoke: one released example completes, finite states, expected frames and shapes, and reproduction discrepancy within a predeclared tolerance or explained versus official result. Installation failure or missing weights => blocked/unavailable, never poor physics.
G2 input parity: assert split IDs, camera/time lists, modality declarations, coordinate/force units and controller trajectories match within each paired comparison group. Assert D0+D1 input hash shared by methods, except documented native preprocessing.
G3 control/adapter parity: zero-intervention run equals native original numerically; known-force and prescribed-position unit tests; reset-state equality. Fail => adapter-only or exclude supported task before cohort outcomes, retaining reason.
G4 observation validity: deformed visibility and valid correspondence checks, noise injected only after measurement formation; identify supplied tracks versus inferred tracks. Failed observations retained and protocol-defined, never silently dropped.
G5 prospective freeze: sha256 checks for protocol/source/data/point predictions/risk/action. Scoring rejects changed hashes and existing outcome files. No target-bearing arrays accessible to fitting/planning code except all-hypothesis model predictions.
G6 same evidence: assert identical observation values for methods choosing same D1; replay each native refit from D0 checkpoint with D1 only. Cross-check frozen native and separately refit output identities/names.
G7 outcome completeness: expected cases/tasks/seeds count exactly; any failure has a record and predeclared penalty/status. No silent reruns or best-seed selection.
G8 independent metrics: a second script recomputes all risks, errors, intervals and paired contrasts from archived predictions without importing training code; check interval endpoints on atomic posteriors.
G9 release: all comparisons labeled native/adapted/supplied-geometry, all unsupported cells visible, raw-data availability stated, reproduction commands and environment locks saved. Native qualification and negative outcomes included.

DECISION
Start native qualification and supported-case discovery for the full requested roster in parallel with the paired protocol. Do not build another neural architecture first. Only commit to a shared numerical leaderboard after G0-G3 establish compatible tasks. The immediate scientific target is a valid paired rendering/changed-interaction comparison and honest risk monitoring; an assumed win is not a completion criterion. If fewer methods qualify, report that the original breadth request remains partially unmet rather than substitute stem/bowl reference experiments for missing native runs.
