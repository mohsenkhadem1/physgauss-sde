2. MASIV (native mechanics, constructed two-world ambiguity)
Two density/material-scale worlds give identical passive rollouts (~1e-4 mm; PSNR >103 dB).
Under localized forces they differ: torus 20 N final 8.13 mm raw / 1.61 mm after rigid
alignment; ellipsoid 8.65 / 1.41 mm. Original Gaussian-load gaps (~14-16 mm) were almost
entirely rigid (0.04 mm aligned) and must not be called elastic separation.
One rendered-centroid calibration (sigma 0.5 px), 400 noise trials:
prior error 4.20 mm, failure 0.5 -> posterior error 0, failure 0.
Posterior risk: torus mean 0.0044 (max 0.36), ellipsoid 0.0002; Brier <=0.0008.
Same-evidence MAP has identical accuracy; truth is in the hypothesis set by construction.
Contact uses native position clipping (283 coordinates at bound in every run).

3. M-PhyGs (native Warp MPM, supplied parameters)
Second interaction (two E/rho worlds, 100 noise repeats each): held gap 6.0e-4
native units (tolerance 1e-4); prior failure 0.5 -> 0 after calibration; same-evidence MAP identical.
Shared shapes v01: FAILED physical qualification (collapse to native clamp); retained.
Shared shapes v02 (floor raised to 3dx), audited here for the first time:
  passive pairs identical (2e-5 mm); held 20 N z: torus 5.84 mm final raw / 0.45 aligned,
  ellipsoid 13.97 / 0.45 mm. Differences are mostly rigid displacement.
  Physical gate: no clamp coordinates, height preserved; floor penetration torus 3.6 mm,
  ellipsoid 6.9-7.9 mm. Passes a 0.5-dx (15.6 mm) gate, FAILS a strict 5 mm gate. Both
  thresholds were set by the auditor after v01 was known. Min deformation Jacobian 0.77-0.81
  even when passive (local compression at sticky floor), far above bulk gravity strain.

AUDIT FINDINGS AND FIXES MADE IN THIS PASS
- GIC physics stage crashed (camera fid/transforms on CPU from the 11GB offload option).
  Fixed by a physics-stage config with GPU-resident cameras (upstream default); the
  completed 40k appearance checkpoint was reused, hashed in gic-appearance-checkpoint.sha256.
- gic_physics_evaluate.py built optimizer params from cfg_args (no optimizer fields);
  fixed to native defaults + --reg_scale --reg_alpha, matching the native run.
- gic_counterfactual.py exhausted Taichi memory with six simulators in one process;
  now one process per case. Failed first-attempt logs retained (*-attempt1-failed.log).
- GIC eval scripts now archive raw renders so the paired foreground metric is computed
  independently (they had not been run before this change; no outcome was seen first).
- PAC-NeRF prefix results recorded nu=None (lookup bug); true fitted nu=0.281 from checkpoint.
- PAC-NeRF counterfactual replays use dt/4, not the scored forecast's native dt.
- M-PhyGs v02 shared-shape runs had no audit (script hard-coded v01); added v02 audit.
- Raw Chamfer is density-biased; count-matched comparison added.
- Independent recomputation (G8): crossmethod-independent-audit.json reproduces every PAC-NeRF
  per-frame PSNR within 1e-3 dB and the frozen baseline rows; reads archives only.

LIMITS
One scene (Torus), one seed per method, synthetic data with native-solver ground truth.
This is a case study, not a benchmark win. No calibrated-force or position-controlled
held interaction exists for PAC-NeRF/GIC natively; MASIV/M-PhyGs ambiguity studies use
supplied parameters and two-world hypothesis sets that contain the truth.
