DECISION
A genuine new conditional rectified-flow posterior can use the existing Isaac RGB-D sensor and shared frozen learned forward operator. This tests our posterior algorithm on external observation interfaces; it does NOT transfer the six-parameter FEM Gaussian-boundary model unchanged. The shared decoder is a learned teacher, not a validated physical solver. Its errors must remain separate from inference errors.

CLAIM LIMITS AND NEXT IMPLEMENTATION
This is a global restricted25D physical-code posterior. It is not a learned spatial Gaussian contact field, contact discovery, force observability proof, reliable uncertainty by construction, arbitrary unseen interaction generalization, or calibrated real-world mechanics. OOD can be stated only for the actual held-out layout/material split; all four force families are known. To test a novel force family requires a separately frozen leave-family-out experiment and a decoder that can represent that family.
Next concrete work: (1) strict-prefix role-checked cache + source/array contracts and a small TRAIN-only teacher API smoke; (2) freeze prospective training/inference protocol and train fresh adapter, then validation-only selection; (3) seal predictions for all76 exposed cases and run existing evaluator under matched observation/draw budgets. This is useful new conditional-flow evidence without relabelling the archived model as ours.
