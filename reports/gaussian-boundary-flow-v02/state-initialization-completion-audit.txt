Does raw mechanics use the observed cutoff state?
No explicit state assimilation occurs. package_campaign_v03 infers response logits
from relative observed-prefix features. ObjectBoundaryBackendRevision.rollout then
starts from rest and computes canonical quasistatic equilibria through every known
command frame. The next solve is initialized with its OWN preceding equilibrium,
not observed object geometry or velocity. Observation data influence theta, but not
an independent cutoff x/v state. Relative features additionally remove the modeled
frame-zero equilibrium mismatch from the inverse objective. Calling this prediction
'conditioned on observed state' would overstate what the algorithm does.

3. Evaluate the UNCHANGED mechanical residual/energy and minJ at that candidate.
   Re-solve only the SAME cutoff command, from original and corrected initial guesses,

If the correction fits observations but force residual is large and relaxation
returns to the old shape, initial solver guess is not the solution: constitutive,
attachment/rest-strain or missing-load model adequacy is the bottleneck. If branches
persist, investigate observability/branch selection before changing architecture.
This test is useful because a unique quasistatic equilibrium has no independent
initial-state memory; simply warm-starting at the observed state cannot fix a
wrong forward law. A true dynamic state estimator needs x/v and separately qualified
integration. Neither invented balancing bodyloads nor mesh rebasing provides that.
