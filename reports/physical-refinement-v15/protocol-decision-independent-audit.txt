Prospective decision audit: physical ambiguity and refinement v15
Status: PROPOSED DESIGN, NOT a source/data freeze or a numerical qualification.
Read attachment 51228e39 and existing position_ood fixture/reference workflow. No new reserved responses read. Prior benchmarks are immutable evidence, not a development pool for this new test.

The first study should test one claim: under the same position-commanded action interface, does acquiring evidence reduce error on previously unobserved physical responses, and does choosing that evidence beat strong fixed/random choices? It must separately measure acquiring information and selecting useful information. This is a controlled same-family numerical identification study unless an independent constitutive law or engine is actually included.

BOUND FIRST COHORT
Use four development scenes (two per ambiguity type) to settle geometry, actions, solver resolution, likelihood discrepancy and fixed-policy choice. Then freeze twelve newly sampled reserved scenes, six per type, with disjoint parameter combinations and scene/noise seeds. All twelve remain in every denominator. The independent sampling unit is the scene/object, not its views, repeated noise realizations or test actions. Six objects per type supports descriptive paired evidence, not a strong population-level calibration claim. Known outer geometry, cameras, density, tool geometry and prescribed command history are declared common inputs; hidden support/material labels are forbidden inputs.

Type S: visually occluded support configuration. Two distinct rear/underside clamp layouts have near-identical initial front RGB-D and neutral-state motion, but different mechanical responses. A permissible side/rear view can see actual fixture geometry. The same fixture geometry determines both rendering and mechanical attachment. Merely displaying a color that encodes the hidden support class is not a view experiment. Mechanical clamp geometry and mask changes must be recorded together.
Type M: identical outer appearance with hidden asymmetric stiffness inclusion/gradient. Passive static views carry no material label; a spatially varied position-driven indentation/shear distinguishes heterogeneous stiffness ratios. A uniformly scaled homogeneous stiffness family is an explicit negative identifiability control, not the main material-learning demonstration.

IDENTIFIABILITY AND MODALITIES
For quasi-static hyperelasticity with all prescribed displacements and no independently known load scale, multiplying every elastic modulus by a common constant scales the energy and reactions but does not change the displacement minimizer. Therefore surface motion alone cannot identify absolute stiffness. Known gravity/density or an independently calibrated compliant tool can break that invariance, but their values then become part of the measurement model. Penalty attachments/contact stiffness can also spuriously break it; never attribute this numerical scale to physical information.
Track V (primary): RGB-D or an explicitly labeled rendered visible-surface-position measurement; no measured force input. Score heterogeneous ratio/support response identification and predictive displacement, with force prediction as a separately reported potentially unidentifiable output.
Track V+F (secondary, separate results): identical position-commanded interventions with an observed reaction-force trace and fixed sensor noise. Force is a measurement/output, not the commanded action input. Compare all policies and estimators within the same modality track. Never compare a force-observing physical policy against a vision-only baseline as if acquisition budgets matched.

ACTION/OBSERVATION CONTRACT
A command is a time/load-parameterized tool position path with prescribed orientation and known geometry. For the bounded first study use quasi-static smooth loading/unloading, supported indentation and shear rather than adding unqualified impact/slip dynamics. This does not claim performance on dropping, friction transitions or arbitrary contact.
Each acquisition slot offers four fixed camera views and four safe position probes. Views acquire one fixed-resolution image pair; probes acquire the same predeclared number of RGB-D frames and, only in V+F, the same force samples. Compare budgets k=0,1,2, with no-replacement acquisitions. Equal slots are an information-budget convention, not equal robot time/energy; disclose image/frame/sample counts and runtime separately. Both policy classes receive the same current data and may use the same candidate acquisition set.
Policies: no update; fixed view; fixed probe; strongest development-selected fixed two-step schedule; uniform random acquisitions (predeclared common seeds, scene is still the statistical unit); expected rendered-observation uncertainty; expected physical predictive-risk reduction. The latter evaluates hypothetical observations under its current belief, never reads the actual unchosen response. Publish acquisition frequencies/ties; a policy identical to the fixed schedule is not evidence of an active-selection advantage.

SEALING AND ADVERSARIAL PAIRS
Use development-only design-query trajectories to engineer ambiguity and to define the physical policy's risk functional. Do not maximize pair separation using an eventual reserved action response. The attachment's optimization over a reserved action would contaminate a test if used to construct/tune the pairs. Freeze separate acquisition, design-query and held-out action lists: e.g. unseen locations, diagonal directions and amplitudes for the latter, with four test trajectories per scene. The primary cohort then contains 48 reserved action responses, reused only for evaluation at budgets 0/1/2. Test commands may be public after freeze for prediction; their responses remain outside inference and acquisition processes. Prefer separate input-only exports and a scorer that cannot import targets until all policy/action forecasts are committed. A posterior-risk policy may use design queries, not the evaluator's actual target trajectories.
Publish an explicit initial ambiguity measurement for each scene pair using the same observation/noise model; do not selectively drop fresh pairs that fail to look ambiguous. Pair construction and thresholds are development decisions. Show model predictions from all plausible hypotheses, rather than selecting a visually convenient example after testing.

BELIEF AND STRONG CONTROLS
Start with a finite, inspectable hypothesis library over support alternatives, heterogeneous stiffness ratios and nuisance parameters. Use the same mechanics and renderer per hypothesis and one fixed prior. Compute normalized likelihoods in log space with fixed observation noise plus independently estimated development numerical/model discrepancy. Avoid treating millions of correlated image pixels as independent measurements. Sparse predeclared samples, block likelihoods or an explicit covariance model are more defensible. A finite grid with ground truth exactly on it is an easy closed-world test; use disjoint off-grid reserved parameters and report posterior model mismatch. A small explicit numerical posterior is an appropriate reference before amortizing with a network.
Compare posterior predictive mean, ordinary MAP/least-squares FEM using the same observations, nominal/frozen FEM, and a position-conditioned empirical deformation baseline where feasible. A visual-only Gaussian renderer that is not actually implemented must not be represented by a differently privileged mechanics surrogate. Material-attached Gaussians can be the common observation renderer without claiming new reconstruction architecture. Freeze any neural baseline before reserved inference; report unavailable baselines honestly rather than rename substitutes.

NUMERICAL ADMISSION BEFORE FREEZE
Reuse position_ood nonlinear mechanics only through a new namespace; record actual constitutive law, attachment model, body loads, free versus prescribed degrees of freedom and reference/predictor discretizations. Independently verify analytic small-strain response, positive deformation Jacobian, converged free residual and correct reaction/energy-work signs. Run mesh refinement and load-increment refinement on both ambiguity types and material/support extremes. Forces and deformation both require qualification. A stiff penalty mesh may yield stable displacements but biased reaction estimates.
For an approximately 80 mm block, an initial proposed development gate is <=0.05 mm common-query displacement and aligned-shape change, <=2% normalized reaction-curve change with a declared absolute near-zero force floor, and minimum J>0.1. Solver residual should be negligible relative to measured reaction scale (target relative 1e-6). These are design proposals, not retrospective pass declarations; physics agent should fix physically meaningful dimensional force floor before any reserved generation. Choose resolution only from development. Two-resolution agreement is not a rigorous continuum error bound.
Require the intended primary deformation signal to exceed both numerical reference uncertainty and sensor displacement noise by at least a predeclared factor (suggest 5), and report the absolute values plus rigid-removed/world RMS ratio. This is a development design gate, not a rule for excluding inconvenient reserved outcomes. Reference failures remain explicit failed/unqualified rows; report fixed-denominator and qualified sensitivity results separately. Do not pool an unqualified stress case into a primary gain.

EVALUATION AND UNCERTAINTY
Primary: held-action world and rigid-aligned shape trajectory RMSE, reported separately by ambiguity type and modality, and measured gain from k=0 at each budget. Reaction-curve error is separate with physical units and a fixed normalization; distinguish no-force-input prediction from force-observing refinement. Include local strain only with common material-coordinate interpolation and adequate numerical qualification.
Rendering: score novel-view RGB/depth from the exact same predicted mechanical state. A shared perfect rest geometry/renderer is a controlled ambiguity test, not evidence of learned visual reconstruction. Compare visual-metric bands and physical errors without claiming that a preconstructed invisible interior proves a broad empirical correlation result.
Uncertainty: report predictive interval coverage, interval width, proper score (e.g. energy score for vector responses), and realized held-out squared error versus predicted risk before/after acquisition. State whether intervals concern latent mechanics or noisy observations; add sensor noise only for the latter. Bayesian variance shrinkage or posterior entropy reduction is not measured improvement. A collapsed categorical posterior can be confidently wrong when truth is off-grid, noise is correlated or mechanics are misspecified. Report these failure modes and parameter coverage separately from predictive coverage.
Use object/scene-clustered paired intervals; include all actions and acquisition seeds within the resampled scene. With twelve scenes/six per type, intervals are descriptive and likely wide. Preserve complete counts and method failures. Predeclare fixed examples for side-by-side rendered, deformation and force-response videos.

DELIVERABLE/CLAIM BOUNDARY
A successful first study establishes a measurable visual/physical ambiguity and whether an extra view or intervention improves qualified synthetic held-action prediction. Superiority of risk selection requires beating the development-selected fixed and random policies, not just beating no acquisition. Absolute material recovery, real-world mechanics, general contact, learned Gaussian reconstruction and CVPR-level novelty remain separate claims requiring separate evidence. No external literature claim in this audit was independently verified.

ROOT COORDINATION ADDENDUM (before any v15 reserved results)
Make budget TWO the primary acquisition comparison; budgets zero and one are diagnostics. With identical D0, prior and acquisition library, a deterministic policy necessarily chooses the same first action for every scene. It cannot demonstrate first-step scene adaptation or outperform a genuinely optimal fixed first action by virtue of being adaptive. The second choice must condition on the first measured response. Compare against the strongest development-selected ordered two-action schedule; random sampling is without replacement and visual/physical policies have the identical observation history. Report branching frequencies conditioned on first observation, and distinguish task-adaptive schedules from scene adaptation.
Each mechanical probe starts from an independent reset to the declared neutral state, with identical settling/support conditions. Query two changes the belief, not the physical initial condition; it cannot inherit hidden deformation or plastic state from query one. Rendering new passive views also uses this declared neutral state. If a future experiment instead acquires a new view of a deformed state, that is a different measurement contract requiring explicit state/history handling.
Use the finite on-grid development pilot solely to test likelihood/action implementation and numerical identifiability. The primary reserved material parameters are continuous/off-grid draws fixed before response generation. A closed finite-family demonstration may be reported as a diagnostic, not as calibration validation for unknown materials. No post-reserved expansion of the hypothesis set or retuning of the discrepancy likelihood is allowed in this campaign's primary result.
