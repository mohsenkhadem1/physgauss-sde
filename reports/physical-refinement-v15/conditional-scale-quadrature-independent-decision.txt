Conditional-scale integration decision: prospective development repair
The failed global scale quadrature remains a recorded numerical failure. Moving to conditional quadrature changes the integration coordinates, not mechanics, noise, prior or observations. This is a principled bounded development repair before test access, contingent on independent validation.

For each geometry hypothesis h, stack acquired whitened wrench predictions w and measurements y. The likelihood as a function of common scale s is exp(-A s²/2+B s+C), where A=wᵀw, B=wᵀy, C=-yᵀy/2 plus Gaussian normalization. RGB-D contributes a scale-independent likelihood. For the fixed log-uniform prior on[a,b]=[.75,1.5], p(s)=1/[s log(b/a)]. For A>0 define μ=B/A, σ=1/sqrt(A), α=(a−μ)/σ, β=(b−μ)/σ and M=Φ(β)−Φ(α). Let q be Normal(μ,σ²) truncated to[a,b]. Then
  Z_h = exp(C+B²/(2A)) σ sqrt(2π) M E_q[1/s] / log(b/a),
  p(s|h,y) = q(s)/[s E_q(1/s)],
  E[s^k|h,y] = E_q[s^(k−1)]/E_q[1/s].
Transform u∈[0,1] through the truncated-normal inverse CDF; Gauss–Legendre nodes/weights integrate these expectations. Conditional posterior node weights are proportional to quadrature_weight/s. Integrate the geometry evidence Z_h into its mixture weight; normalizing each conditional scale posterior alone discards evidence about geometry. Include the complete Gaussian normalization in C when reporting evidence. Constants may cancel in explicitly shared-mixture comparisons but should not vanish inconsistently between integration methods.

Stability requirements
1. Compute log M using log-CDF differences in the left tail and log-survival differences in the right tail. Use stable logdiffexp/expm1; direct subtraction of nearly equal CDFs fails. The middle interval can also use stable log differences. Test both positive and negative tails.
2. Gauss nodes lie strictly inside(0,1), avoiding infinite endpoint quantiles. Check all returned scales are finite, ordered and within bounds. Strong likelihoods outside the prior can concentrate at a boundary; boundary concentration is a legitimate posterior, not grounds for clipping μ into the prior and pretending the distribution is centered there.
3. C+B²/(2A) and tail normalization can catastrophically cancel when μ is distant. Evaluate shifted log likelihood from original whitened residuals at a reference scale (such as clipped μ), and combine normalization in log space. Check the resulting evidence against a separately implemented direct-residual integrator, not only the same completed-square formula.
4. A=0 implies w=0 and B=0 under positive-definite whitening: retain the exact log-uniform prior, scale-independent likelihood and analytic moments. For near-zero/broad A, retain the earlier log-scale integrator with a fixed criterion and validate the branch transition. Do not divide by tiny A or silently set a nonzero B to zero. A negative beyond rounding tolerance is a bug.
5. Repeated observed wrenches must use the declared independent-packet covariance contract. If calibration biases are shared across acquisitions, blindly summing independent quadratic likelihoods is wrong. Current synthetic independent-packet assumptions should remain explicit. The RGB-D/wrench block diagonal model ensures visual observations do not acquire artificial scale dependence through a mixed transform.

Bounded validation plan
Compare conditional25/49, then49/97 if needed, on the same fixed development history census used for the failed global quadrature. Keep existing evidence/mean/std/quantile tolerances. Report original global-grid comparisons rather than replacing them. The small scalar integral also permits an independent adaptive quadrature reference using original residual likelihood in log-scale; provide integration breakpoints around the likelihood mode and several widths so the adaptive algorithm cannot entirely miss a narrow peak. Shift the exponent by a finite reference maximum to avoid underflow. The independent implementation should not reuse truncated-normal quadrature internals. Verify adaptive error estimates by tighter tolerances/a second split, not by trusting one default return code.
Synthetic operator cases before development validation: no wrench(A=0); weak/broad likelihood; narrow interior peak; peaks just inside each bound; peaks outside both bounds; several repeated measurements; non-unit covariance; known analytic/numerical moments; scale-independent RGB-D multiplied in; multiple geometry hypotheses where evidence, not only conditional means, distinguishes them. Confirm predictive mixture mean/variance and geometry weights, not only scalar scale moments. Keep all inputs to these tests synthetic or development-only.
If conditional97 or the independent integral still fails the predeclared checks, stop calling the posterior a trustworthy reference. Do not weaken sensor noise, omit failure histories or claim calibration from collapsed intervals. This repair does not resolve gradient-grid discretization; that remains a separate development convergence check.

Policy score integration
Changing the conditional scale particles changes how fantasies must be sampled: draw geometry from its evidence-updated mixture, then scale from that geometry's conditional distribution. Do not accidentally retain the unconditional common scale grid or draw every geometry from the same conditional scale posterior. Compare expected risk and action scores with recorded Monte Carlo error; quadrature convergence and Monte Carlo precision are separate numerical issues.

Prediction/rendering convention
Use posterior predictive means as statistical estimators for squared response loss; a mean shape need not solve mechanics. Visual/physical-gap plots should use the SAME hypothesis state for mechanics and rendering. A MAP or sampled state can supply the corresponding video. E[R(X)] is the predictive image mean, whereas R(E[X]) is a different nonlinear construction. Do not label either the latter or a posterior mean displacement as necessarily PDE-admissible.
