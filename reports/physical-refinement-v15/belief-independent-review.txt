Bounded hypothesis design recommendation
Maintain four development scenes and twelve reserved scenes as proposed. Do not add more physical dimensions simply because the belief API permits them. For the current two support layouts and graded heterogeneity family, a practical initial library is:
  support in {parallel,crossed}; g in {-0.8,-0.4,0,0.4,0.8}; common mechanical scale s in {0.5,1,2}: 30 hypotheses.
Here s scales material E and both physical Robin fixture stiffnesses together, leaving position-driven zero-gravity equilibrium unchanged but scaling reactions. This makes the unidentifiable nuisance scale explicit rather than spuriously learnable from a fixed numerical penalty. It is not a claim that arbitrary independent E/K combinations are covered. If the intended unknowns include independent E/K ratios, replace the common-scale factor by an explicitly bounded ratio grid and state that stronger inverse problem; do not silently conflate the two.
Development-only resolution diagnostic: compare g spacing 0.4 above with spacing 0.2 (54 hypotheses) on the same four development scenes and fixed candidate/design queries. Compare posterior predictive means, predictive risk and first/second query choices, not just parameter histograms. Suggested stop rule before outcomes: refine once to 54 if response differences exceed the predeclared numerical/measurement resolution or acquisition ranking changes beyond its Monte Carlo uncertainty; then freeze the chosen library. No open-ended grid search. For V+F, assess scale grid resolution separately: a three-point scale grid is only a coarse categorical uncertainty model and is not adequate for claiming continuous absolute-stiffness credible intervals. Report force prediction error/proper scores; do not advertise parameter interval calibration from it.
Reserved g values should be sampled continuously inside the declared range, avoiding grid nodes, and scale continuously log-uniform within [0.5,2] if that nuisance is studied. The same support classes test new parameter combinations, not unseen support topology. Draw all reserved values/seeds before generating responses; never replace difficult draws. Uniform discrete weights imply a discrete prior and must be stated; nonuniform/adaptive quadrature needs corresponding prior cell weights.

Development-only discrepancy plan
Separate known sensor noise, numerical discrepancy and hypothesis-grid approximation. At each development truth and fixed candidate/design query, compare the coarse predictor and qualified finer reference at the SAME physical parameter values. Estimate numerical discrepancy from those paired residuals, per declared modality/feature block. Do not use a best-fit residual to tune an arbitrarily large noise term that hides inference error. Freeze a conservative positive variance floor based on the maximum development block RMS (squared), plus the specified sensor variance; save individual residuals and the exact aggregation rule. If a systematic bias remains, report it; a zero-mean diagonal variance does not remove bias.
Measure grid approximation separately at fixed development off-grid/midpoint parameters. Either freeze the refined grid or include a separately declared approximation discrepancy based on these development-only residuals. Do not inflate discrepancy after reserved coverage is observed. Sparse/block features are needed because diagonal likelihoods assume independence; copying a residual variance to thousands of correlated pixels would still cause false certainty.
With only four development scenes this discrepancy is an engineering uncertainty model, not an empirically calibrated population distribution. For latent physical response intervals, sensor noise is not part of latent mechanics; add sensor variance only when forecasting an actual noisy observation. Report realized held-response error, coverage, interval width and proper scores separately. The common-scale negative control must preserve the scale marginal in vision-only updates up to numerical tolerances; V+F may update it. This is a particularly useful end-to-end invariant test.

Visible fixture mapping assessment
fixture_geometry.py samples the same footprint() used by SmoothMaterialFixture. state_scene.py obtains object surface and inner ligament endpoints from the same Q2 displacement field, with outer endpoints from prescribed poses. This is coherent within a declared synthetic homogenized attachment-density model. It is not a resolved continuum derivation of fixture mechanics: straight visible ligaments have different axial/transverse stiffness, whereas the Robin law is isotropic. A camera can identify the hypothesized spatial attachment-density pattern because that geometry-to-mechanics correspondence is an assumed known model. Claim support-layout refinement under that prior, not generic physical recovery of real fixture mechanics from appearance. Unknown total stiffness is correctly absent from appearance.
The cross-section mesh is an octagon. With radius sqrt(area/pi), its actual area is 2sqrt(2)/pi times the nominal circular area. Normalized areas remain proportional to footprint, but declared total geometric area is inaccurate by about 10%. Requested prefreeze correction or explicit nominal/actual distinction; agent owns that change. Render grid midpoint sampling and continuum quadrature are distinct discretizations of one footprint and should be described as such, not asserted identical finite element spring matrices.
