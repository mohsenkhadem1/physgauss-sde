Its material endpoints are 75–150 kPa; the earlier 50–150 kPa cohort draft remains a separate unlaunched proposal. A failed domain check prevents population admission; it is retained and diagnosed rather than silently removed.

The next reference should contain one continuous unknown, log Young modulus, and two explicitly enumerated support hypotheses: both fixed end faces, or two fixed bottom quarter patches. Poisson ratio, density, gravity, object geometry, actuator location and applied force remain known. These are ideal perfectly fixed supports with two known candidate layouts. This does not infer compliant fixtures, an arbitrary boundary field, unknown density or unknown forces. Density and stiffness can trade off under gravity, so unknown density must not be added without a separate identification experiment.

Use the same polynomial stable-NH constitutive law as the qualified forward solver. The logarithmic-NH bar oracle is a different model and cannot provide this family's response. Gravity-only equilibrium is the prefix; independent resets under public midspan forces are candidate acquisitions. This is prediction of another equilibrium, not dynamic forecasting or an established settling-time model.

## First establish the forward and identification limits

After the mechanics phase terminates, compare low/high material response within each support and the two support responses at matched material and force. Use the same 63 physical query points, bulk strain/nonrigid displacement, and surface visibility. Report differences relative to both the spatial indicator and the proposed observation noise. A visible rigid displacement alone does not establish information about elasticity. Corner checks and a finite interior set are evidence at those states, not a rigorous uniform material-domain error bound.

Before synthetic observations, test whether the two support families produce near-identical prefix predictions anywhere over the material range. Plot the minimum cross-family response distance after optimizing material, with all sensor components whitened by their stipulated noise. Repeat after each candidate force. This exposes material/support ambiguity rather than treating a narrow material interval as successful identification. Distinguish model-conditional identifiability from any real-world claim.

Start with a separately labeled ideal point-observation diagnostic to isolate mechanics and numerical integration. Select a small fixed set of surface material points before observations; do not use the full displacement field as an inference input. An example sensor specification is independent 200 µm Cartesian noise, but sensor points, noise, priors and seeds must be frozen in an execution protocol before drawing data. This example is not an adopted noise calibration. A dense RGB-D likelihood requires its own camera, visibility, missing-depth and renderer-convergence controls; ideal tracked points cannot stand in for that experiment.

## Reference posterior and numerical qualification

For the first controlled diagnostic, propose equal prior probability for the two support categories and a uniform prior in log E over the full finite 75–150 kPa range. Enumerate supports exactly. For known acquired loads and ideal sensor vector y, evaluate the stipulated Gaussian likelihood using the nonlinear equilibrium responses, retaining its normalization. Combine acquisitions only under the declared independent-noise model. Shared registration/calibration error would require an explicit nuisance variable rather than independent copies of the same error.

The posterior normalizer is the sum of two one-dimensional log-E integrals. Use adaptive integration with log-likelihood scaling, cache direct forward evaluations by all physical inputs and solver/source hashes, and retain prior endpoints. There is no reason to introduce MCMC for this small reference. A numerical posterior still needs demonstrated convergence: repeat integration at tighter tolerances, use an independent integration rule, and compare normalizers, support probabilities, material CDFs/quantiles, and target-field predictive means and intervals. A large integration-node count alone is not a qualification.

Direct nonlinear solves are the reference. If an interpolated forward table is needed for cost, build and validate it separately on prospectively held-out material values and all acquired/target loads. Retain original equilibrium, wrench, constraint and Jacobian gates at every direct state. Test refinement in both the mesh and the interpolation grid; do not merge their errors into a single reported solver residual. The spatial engineering indicator is not an interval bound that can be automatically propagated through the likelihood.

Forward error must also be assessed at the likelihood level. A 20 µm component error is not automatically negligible compared with 200 µm noise when many components are combined. At the same synthetic observations, compare log-likelihoods and posterior/predictive summaries using independent finer direct responses. Freeze acceptable changes relative to the intended prediction and action gaps before evaluation. Resolve meaningful changes with additional forward accuracy; widening or renaming a material interval does not fix a biased likelihood.

## Prediction and acquisition comparison

Use one canonical withheld static target load for every policy. Its state needs independent physical and spatial checks even if its force lies between qualified endpoints. Freeze target selection before observations. Compare the prior predictive, prefix-only reference posterior, and posterior after one additional equal-budget acquisition. The true-parameter nonlinear response is a separately labeled privileged oracle. Include persistence, a fitted linear mechanical response, fixed force/view choices, random choice and a simple geometry-based rule.

Candidate forces must act at the public free midspan patch and have identical values for every material/support hypothesis. A new camera view and a new poke are different acquisition types with different observation and actuation costs; establish a stated equal budget before combining them in a ranking. Camera-only acquisition observes the current equilibrium and supplies no new mechanical excitation. Independent-reset probes do not establish a policy for an object carrying dynamic memory or undergoing contact.

For model-based action choice, minimize posterior expected error on the canonical target, integrated over candidate outcomes; also record information gain as a distinct criterion. Refine outcome integration and material integration until the action ranking or a declared tie is stable. Freeze choices before generating action outcomes, and freeze posterior predictions before exposing target truth. A higher effective sample size or narrower interval is not proof that the action is better.

Use separate development, calibration and test whole objects. Keep every view, reset and counterfactual of an object in its assigned role. Report paired prediction improvements with object-level uncertainty, material/support recovery separately, interval widths alongside coverage, and confident failures. TEST remains closed until development/calibration and numerical gates pass. Neural amortization, Gaussian scene reconstruction and general boundary fields follow only if this reference and strong baselines reveal a concrete need.
