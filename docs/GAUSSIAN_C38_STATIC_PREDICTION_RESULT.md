# Static supplied-physics prediction result

The strongest new result is simple: with material and supports supplied, a rest-tangent physical model already predicts these static responses very accurately. At the finest mesh, pooled coordinate RMSE across14 configurations and63 common material points is **3.7884 µm**, versus **686.595 µm** for no motion and **438.739 µm** for the rigid fit derived from the linear prediction. Maximum point error is **23.2743 µm**; prediction approximation error is distinct from the20 µm mesh-indicator threshold. No universal20 µm prediction-error claim is made. All28 sealed case/resolution comparisons completed. See the [full report](../runs/operator-dev/c38-static-linear-scoring-v01/REPORT.md).

This is a supplied-physics oracle, not recovery of material/support from observations, an RGB-D predictor, a neural-network result or a temporal forecast. The record does not justify adding network complexity to solve this forward problem. The next controlled question is whether inference can retain calibrated uncertainty and whether a chosen probe helps more than a strong fixed action.

This addresses the concern that an earlier experiment was nearly all rigid motion, but it is a different experiment and not a matched population comparison.
