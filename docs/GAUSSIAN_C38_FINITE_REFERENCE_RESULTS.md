# Finite static reference and corrected drop checks

All **14 declared static cases** now pass the unchanged conditional displacement check at the same **63 material points**. Their finest indicators range from **1.662 to 13.381 µm**, below the 20 µm threshold. This joins twelve new cases to two exact previously completed cases: 28 fine fields in total, with no failed case dropped. The new stage took 1,881 seconds. All original physical checks and independent original-Torch direction checks pass. See the [complete finite-case report](../runs/operator-dev/c38-graded-family-warp-v01/REPORT.md).

This is a finite engineering result at those query points. It is not a rigorous error bound, a certificate over continuous material/force values, a surface/pixel error result or peak-stress convergence. Peak sampled strain ranges from 5.26% to 61.27%, while the volume 99th percentile ranges from 0.61% to 3.26%; the fixed-edge peak still grows with refinement. Earlier uniform-mesh failures, graded failures and the original metadata-loss statement remain in the record. No training dataset is admitted by this report alone.

The drop reference now explicitly corrects **two** integrations: the old bulk rule is replaced by degree-six Keast integration, and pointwise surface quadrature is replaced by root-split contact integration. At identical saved shapes, the bulk diagnostic found old-rule force errors of 0.269–0.538 mN; the larger surface errors were already isolated separately. The new CPU and GPU implementations agree with the independent references. The material, gravity, full consistent mass and finite contact stiffness were retained.

The corrected fixed-96-tet drop passed its two-accuracy time comparison: maximum node position difference **18.611 nm**, velocity difference **90.325 µm/s** against a 100 µm/s limit, and output-energy difference **15.122 nJ** against 470.88 nJ. The individual accepted-state energy errors were 33.148 and 2.086 nJ. The tighter run used 3,419 accepted steps and 53,303 RHS calls. This is not an isolated speed benchmark, because both quadratures changed. Surface-order stability and spatial accuracy remain separate unresolved checks. See the [completed time comparison](../runs/operator-dev/p2-corrected-contact-reference-v01/result-summary.json).

The separate four-run supported-gravity refinement finished with all physical and time-refinement checks passing, but spatial refinement failed: conditional position and velocity indicators were **55.47 µm** and **47.87 mm/s**, versus limits of 20 µm and 0.1 mm/s. The largest velocity discrepancy occurs at 70.833 ms, not just the initial frame. These trajectories remain unqualified; no filtering or threshold changes were applied. See the [gravity refinement report](../runs/operator-dev/p2-supported-gravity-fine-v01/REPORT.md).

The new static linear baseline has coarse CPU controls and a separately frozen GPU basis/prediction protocol. It uses true or candidate physics, not image inference. Predictions are sealed before any separate nonlinear target scoring. Static-only role/admission and ideal-point export adapters have manufactured controls; an additional wrapper restricts observations to explicitly reviewed material points. Full nodal files do not qualify arbitrary new sensor points. These adapters create no actual cohort, noise realization, neural fit or posterior.

The next [nonlinear-table design](GAUSSIAN_C38_NONLINEAR_TABLE_DESIGN.md) separates interpolation nodes from withheld validation materials, adds an independently checked canonical target force and requires direct forward and numerical posterior checks before probing comparisons. It remains a proposal until its execution prerequisites and resource limits are frozen. Ideal tracked points remain distinct from RGB-D views. Physical Gaussian shape covariance remains distinct from posterior uncertainty. Raw fields, checkpoints, media and model files remain local.
