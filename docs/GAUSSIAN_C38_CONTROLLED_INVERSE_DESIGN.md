# Controlled inverse and probing diagnostic

Design only. No observations, noise arrays, object roles, policy outcomes or physical posterior have been generated by this document. The response-table execution is a separate, already frozen mechanical experiment.

Use a deliberately small inverse problem before training another network: one continuous Young modulus from 75–150 kPa and exactly two known support categories. The unknown category chooses either the existing end clamps or the existing bottom patches. Geometry, density, Poisson ratio, gravity and commanded load remain public and known. This cannot identify arbitrary boundary fields, support compliance or unknown forces.

The latent coordinate is t = log(E/75 kPa)/log(2), with a uniform prior on [0,1] and equal category prior. For acquired ideal tracked points y and a declared covariance R, the likelihood is proportional to exp(−(y−f(E,b))ᵀR⁻¹(y−f(E,b))/2). Only acquired measurements enter this likelihood. A true parameter label, an unacquired probe outcome and the canonical target response belong to the private evaluator. Gaussian particle shape covariance is separate from uncertainty over E, b and future point displacement.

Three inverse-modulus table nodes produce a quadratic displacement interpolant. With fixed Gaussian observation noise, its squared residual is quartic in inverse modulus. This structure permits stationary-point checks and likelihood partitions. Generic adaptive integration agreeing with fixed Gauss rules is insufficient by itself: all can miss the same narrow mode. The current generic posterior helper reports discrepancies and has no physical admission gate. An explicit narrow-mode counterexample and specialised likelihood controls are required before using it to declare convergence. Convergence checks must include normalizer, category probabilities, modulus CDF and quantiles, and canonical-response moments and intervals. A narrow interval from an unresolved quadrature is a failure.

First validate the three-node forward approximation against the two prospectively withheld materials, for both supports, all four forces and both mesh levels, at exactly the qualified 63 material points. Retain failures without moving a withheld material into the table. The prospective interpolation target is 1 µm per point. Passing these finite checks does not certify every material between the endpoints. Compare a likelihood constructed from each withheld direct response with the corresponding interpolated response, and assess how the approximation changes the material/support posterior. Direct-reference and mesh uncertainty must remain separate from simulated sensor noise.

An initial diagnostic can use the four deterministic withheld material/support pairs, with repeated independent stipulated sensor-noise realizations at each pair. These are four physical configurations, irrespective of the number of noise repeats. Coverage must be reported conditionally at each configuration, with the small number of configurations explicit; it is not population calibration over random objects. A later population study needs fresh independently drawn physical configurations and their own forward checks. The sensor, prior, covariance, repeat count and seeds must be frozen in an executable protocol before any draws. Nine existing top material points and 200 µm Cartesian noise remain candidates until that protocol is reviewed; they are not calibrated RGB-D measurements.

The initial acquired state is gravity alone. Each candidate action applies either −2 N or +2 N in a separate static reset with the same material and support. Both actions receive the same observation geometry, noise model and acquisition cost. The canonical target is +1 N, distinct from either probe. Predictions and the chosen action are sealed before exposing the corresponding acquired outcome or target truth. A camera-view action requires a visibility/rendering/sensor model and is outside this ideal-point diagnostic.

Compare the public-data reference posterior with rest persistence and the supplied-physics linear oracle, then compare fixed downward, fixed upward, random, expected-information and expected-predictive-risk actions. Define predictive risk on the canonical target points; reduced parameter entropy alone need not improve deformation prediction. Expected acquisition calculations need their own fixed budget and numerical refinement checks, with design samples independent of actual acquired outcomes. Report paired per-configuration changes, worse-after-probe cases and ties. A strong fixed downward action may remain best; the campaign must retain that outcome rather than tune an adaptive-policy win.

Neural amortization follows only if this controlled reference posterior is reliable and inference cost or observation representation creates a demonstrated need. RGB-D and unseen layouts require a separate experiment. Static equilibria are not future-motion forecasts, and a camera orbit in a visualisation is not an information-gain acquisition result.
