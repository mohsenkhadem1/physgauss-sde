# C38 prediction and probing: implementation stage

**Status: 17 synthetic CPU controls pass. No C38 physical dataset has been admitted, no model has been trained, and no physical probing outcome has been evaluated.** Mesh, physical rate, domain, object counts and final study protocol remain pending independent forward qualification. The tentative 64/16/16/32 division is not a frozen cohort.

The objective is causal deformation forecasting from sparse observations, followed by useful, uncertainty-aware acquisition. Conditional prediction with supplied physical parameters (A) and inference from a public RGB-D prefix (B) are separate tasks. A candidate physical hypothesis may feed a conditional forward model inside B; the true material and support must not become public B features.

## Evidence to reuse

- [Material Gaussians](../experiments/campaign_material_gaussians.py) already transport centers and covariance through a shared compatible field. Physical shape covariance is distinct from posterior uncertainty. The existing implementation is P1; the new P2 adapter uses the actual ten-node interpolation, not corner-only linearization.
- The [old graph predictor](../experiments/campaign_hybrid_predictor.py) and [force-linear variant](../experiments/campaign_hybrid_response.py) require ordered rigid handles and old material/context conventions. They cannot consume a no-handle, zero-drag P2 block unchanged. The new adapter reuses the graph/causal-GRU pattern with the actual fixture and consistent load basis; it introduces no network architecture search.
- The [96-case comparison](../runs/gaussian-campaign-v01/crossed-gaussian-training-v01/final-comparison/REPORT.md) is negative for the neural surrogate: held role errors were about 0.46–0.57 mm versus 9–23 µm for the supplied-physics linear baseline. This used four reused hardware layouts and three material strata; it is not evidence of unseen-layout generalization. These sealed outcomes remain unchanged.
- [Earlier local baselines](GAUSSIAN_BOUNDARY_BASELINES.md) include reconstruction and gap filling. The local PIDG-inspired coordinate/time fit is not official PIDG, and official PIDG training was not completed. A per-scene fit seeing later observations is not an appropriate causal forecasting comparison.
- The [sealed point-support study](GAUSSIAN_ROTATION_UNCERTAINTY.md) provides reusable causal release, joint-discrepancy, simultaneous-band and action controls. It does not establish general boundary inference, calibrated material posteriors or a reliable active-policy advantage. No old test is being rerun to choose this architecture.

## Implemented controls

[Material adapter](../experiments/campaign_c38_gaussians.py): one positive-mass Gaussian per reference P2 tetrahedron, center and local deformation gradient from the ten-node field, and `Sigma = F Sigma0 F.T`. Tet mass is `rho * reference_volume`. This is a local Gaussian approximation at each tet centroid; positive centroid Jacobians are not a certificate for the whole curved P2 element. Positive Gaussian sampling masses do not replace the consistent P2 nodal mass operator.

[Predictor adapter](../experiments/campaign_c38_predictor.py): sparse normalized graph exchange, fixed-capacity two material-frame load-Gaussian feature slots, actual signed consistent force basis, explicit known/candidate physics context, causal GRU control history, zero-drive reference subtraction, and exact prescribed fixture coordinates. There are no dummy rigid handles or artificial positive drag. Coefficient row `i` is held over `(t[i-1], t[i]]`; row zero is unused. The output is a shared nodal field. Transported physical covariance is computed from that field, not predicted as an independent uncertainty head. This conditional decoder does not yet assimilate images or produce a posterior.

[Study controls](../experiments/campaign_c38_study.py): literal complete force-history fingerprints, object/role barriers, source/evidence-bound forward admission, future-only scoring, persistence, constant velocity, rigid angular/COM extrapolation, and paired object bootstrap intervals. The RGB-D payload constructor returns acquired prefix images, masks and cameras, public geometry, and known planned controls. It accepts no material/support/full-state labels. Privileged tracked-point baselines remain separately labeled. The admission schema is a proposed metadata interface; only independently reviewed numerical evidence can make the physical admission true.

[Action controls](../experiments/campaign_c38_actions.py): finite-hypothesis Gaussian working-model information gain and forecast-risk criteria, common fantasy ancestors/noise, deterministic random policy, matched acquisition budgets, and an exclusive source/input-bound choice record written before an actual observation update. An update rejects changed base weights and applies one new likelihood. This small independent-Gaussian control must not replace the existing shared-latent joint-GP update when discrepancy is correlated across observations and targets.

## Gates before physical comparisons

1. **Forward qualification:** root supplies an exact scenario schema and domain-specific spatial, temporal, nonlinear residual and constitutive evidence. Successful process exit alone is insufficient. P2 geometry includes ten-node tets and subdivided surface triangles; physics uses its consistent mass, not positive corner lumping. Contact and unsupported domains need their own qualification.
2. **Frozen dataset:** entire material tuples, support layouts and complete force histories are disjoint across roles; all counterfactual actions of an object share its role. Categories may repeat, but continuous values and layout geometry must be new. Hash disjointness checks identity, not a proof of adequate distributional separation. All planned cases must complete or remain an explicit failed/incomplete study; no label-based filtering.
3. **Prediction:** freeze architecture, seeds, training budget and final-checkpoint policy before fitting. Known-physics A compares the compatible model against supplied-physics linear and independent finite-element reference. Public B uses only past RGB-D and known controls, with persistence/velocity/rigid baselines computed from the same available information. Full-state versions are privileged controls, not sparse-view competitors. Future observations, bidirectional reconstruction and per-scene future fitting are excluded.
4. **Uncertainty:** a small validated two- or three-latent reference posterior must pass independent numerical agreement checks before uncertainty-guided physical claims. The [nonlinear homogeneous-bar reference](GAUSSIAN_NONLINEAR_BAR_INVERSE.md) is a useful numerical control, not a general Gaussian-boundary posterior. Diagnose posterior mismatch and forward discrepancy separately. Calibrate predictive bands on independent calibration objects; report exact object-level coverage intervals, widths and per-domain errors. Numerical convergence does not establish physical or Bayesian calibration.
5. **Actions:** use a controlled reset study initially. Each poke starts at common rest with the same object latents; every policy then predicts the same held-out canonical force program from the same rest state. Views acquire the same number of frames at the common current state. Fixed, random, information-gain and predictive-risk policies receive one action with the same duration/frame/noise budget. Choice uses only public prefix and prior, and freezes before action outcomes and held targets. Object/action-specific observation noise is fixed prospectively and shared when policies choose the same action. Report paired object bootstrap intervals and coverage uncertainty. This makes no persistent-contact or online manipulation claim.

## Resources and remaining interface

Development tests use CPU with two numerical threads. No data generation, GPU inference, fitting, foundation-model download or external spending was performed here. GPU2 remains reserved for prediction after data admission; GPU0/1 forward/contact work and unrelated GPU3 work are untouched. A provisional upper budget is six fixed fits (exchange/no-exchange, three seeds), one job on GPU2 at a time, 600 s/job and 8 GiB allocated memory; this is a ceiling to review after actual P2 node counts and accepted episode length are known, not a launch declaration. Physical data counts and final uncertainty/action sample sizes are not yet frozen.
