# Prospective nonlinear response table and inverse diagnostic

Design only. No additional physical cases, observations, object roles or posterior are created by this document. Execution depends on the remaining 14-case static screen and the supplied-physics baseline checks. The existing finite screen is not a uniform certificate over continuous material values or force amplitudes.

The first reference inverse problem should keep one continuous unknown, Young modulus in 75–150 kPa, and exactly enumerate the two existing fixed-support categories. Density, Poisson ratio, gravity, geometry and applied forces remain known. This is a controlled static problem with ideal tracked material points. It does not infer arbitrary boundary fields, compliant supports, RGB-D correspondences or future dynamics.

A direct nonlinear solve at every integration node would be expensive. A small interpolation table can be a separately tested acceleration, with direct nonlinear solves retained as its reference. Propose three table materials: 75 kPa, the existing geometric midpoint, and 150 kPa. Interpolate nodal displacement in inverse modulus, where the rest-tangent baseline is exactly linear; this does not make nonlinear interpolation exact. Use the two log-material quarter points as prospectively withheld validation materials. Never promote a failed validation point into the table and reuse it as validation.

Propose four known force states: gravity alone, extra vertical −2 N, +2 N, and a new +1 N canonical target. The +1 N target needs its own physical and spatial checks; endpoint checks do not admit it. Prefix observations would use gravity alone. A probe would use an independent reset at either −2 N or +2 N, with the same latent material/support. The canonical target is distinct from either probe. A new camera or other observation type requires a separately stated sensor and equal acquisition budget.

The five materials, two supports and four force states comprise 40 static states. The current 14 states could contribute their exact completed 32/40 fields only after their checks pass. The other 26 states require 52 new fine solves from rest. This is a proposed deterministic development and numerical-validation table, not 40 independent sampled objects or a held-out population. All old failures and exact provenance must remain. The prospective executable protocol must enumerate every state, designate table versus validation materials, freeze gates and cap owned CPU/GPU/disk use before any new solve. Existing immutable workers can be reused without changing their equations or tolerances.

Check nonlinear residuals, 24/80-point agreement, true force/moment balance, exact supports and whole-element Jacobians for every direct state. Check the conditional 32→40 displacement indicator separately at every new material/load. Validate interpolation against the withheld direct responses at both mesh levels, including the fixed physical probes and intended sensor points. A candidate 1 µm interpolation tolerance is a design value to freeze before execution, not a result. Record full-field errors and failures as well. Neither interpolation agreement nor two-mesh agreement supplies a rigorous continuum bound.

After these forward checks, freeze the sensor geometry, stipulated noise covariance, prior, seeds and object roles before drawing observations. The nine top material points used in the earlier separation diagnostic and independent 200 µm Cartesian noise are possible starting choices, not calibrated sensors. Keep ideal points distinct from rendered views. Use a uniform prior in log modulus and an equal prior over support categories unless the execution protocol explicitly chooses otherwise.

The reference posterior needs only two one-dimensional integrals. Compare adaptive integration against an independent fixed quadrature and its refinement. Require agreement in normalizer, support probabilities, material CDFs and quantiles, and target-field predictive means and intervals. Separately compare the nonlinear table with the supplied-physics linear baseline and selected direct finer nonlinear responses at the likelihood and posterior levels. Conditional coverage under the same interpolation table is not independent evidence of physical calibration.

Freeze predictions and action choices before exposing acquired outcomes and canonical target truth. Compare persistence, the supplied-physics linear oracle, the public-data reference posterior, fixed downward/upward probes, random choice, information gain and predictive-risk choice with matched budgets. The finite-corner diagnostic currently favors downward forcing; a strong fixed action can legitimately remain best. Report ties, confident failures and paired object-level uncertainty. Neural amortization and more varied supports or localized probes follow only if this controlled reference exposes a concrete need; each expanded mechanics domain needs its own checks.
