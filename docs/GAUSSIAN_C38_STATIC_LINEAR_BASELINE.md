# Static P2 linear baseline

The [new baseline](../experiments/campaign_c38_static_linear.py) solves the original compatible P2 rest tangent twice per support and reference modulus: once for gravity and once for a known unit surface force. With Poisson ratio fixed, stiffness scales with Young modulus, so a candidate modulus and applied force give the linear displacement by scaling and combining those two responses. It uses the full signed consistent force coefficients, exact fixed supports and an independent original Torch tangent residual check. No artificial time step, damping, lumped mass or label fit is introduced.

Three small CPU controls pass: comparison with an independently assembled sparse tangent for both support layouts, force superposition and modulus scaling, and the small-load limit of an independent sparse nonlinear Newton solve. These controls use the declared coarse mesh. They do not establish fine-mesh accuracy, nonlinear prediction quality or population performance. The linear field itself has no positive-J or nonlinear accuracy guarantee; evaluation must record invalid predictions and cannot repair them silently.

This is a supplied-physics oracle when given the true material and support, or a conditional response to a candidate hypothesis inside an inverse method. It does not infer physics from images. Public-observation prediction must obtain its hypotheses from allowed acquired data and must not feed private truth to this baseline. Its nodal field can use the existing compatible Gaussian transport; Gaussian shape covariance remains distinct from posterior uncertainty. No cohort, images, training or new probing comparison was created.
