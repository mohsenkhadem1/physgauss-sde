# Read-only prediction pipeline audit

No model, observation, object role or inference run was created. Existing sealed comparisons remain unchanged. The current mechanics work is a static-load family screen; even a full 14-point pass will not supply a diverse dynamic forecasting domain.

**Ready components:** `campaign_c38_static_data.py` has an integer acquisition ledger, known load-state table and exact public RGB-D member allowlist. It rejects unacquired ledger entries before reading images. `campaign_c38_data.py` keeps rest geometry public and binds a dynamic private target to an exact admitted path/SHA before its NPZ is opened. `campaign_c38_p2_surface.py` evaluates true six-node faces and checks successive ray-depth/visibility tessellations. `campaign_c38_gaussians.py` transports compatible P2 centroid kernels and local FΣFᵀ while correctly separating physical shape covariance from uncertainty. These are useful building blocks, not an end-to-end acquired-image predictor.

## Reuse and scientific limits

The completed older 96-case known-physics comparison is a warning against another architecture search: the physical linear baseline scored about .00924 mm on force transfer versus roughly .464–.469 mm for the Gaussian neural variants. Those were different P1/rigid-hardware engineering captures; their scores do not transfer to this static block. Reuse their exact-ID comparison and fixed-seed/final-checkpoint conventions, not their labels or physical context.

`pidg_style_baseline.py` explicitly implements a PIDG-inspired per-scene coordinate/time reconstruction model, not the official method or an unseen-poke predictor. Its constitutive helper is logarithmic NH, unlike the current polynomial stable-NH block. `rgbd_geometric_baseline.py` is likewise a reconstruction/interpolation baseline. Neither is presently a valid changed-load physics forecast comparator without a separately labeled causal/static adapter; do not rerun sealed old comparisons to fill that gap.

The existing reset-action utility freezes choice fingerprints before outcomes and uses one canonical target for all policies. Its independent Gaussian working likelihood is not the correlated shared-GP update. For static actions, use acquisition/load-state accounting instead of claiming a measured settling time. Before an expensive population, qualify the continuous-E/support reference and check action-risk gaps against a strong fixed downward action. Current finite endpoint separation favors down > gravity > up in both layouts; adaptive benefit can legitimately be absent. A minimum over four endpoint pairs is not a continuous ambiguity bound. New localized forces or random support locations need new mechanics qualification.

Recommended next implementation order is static admission/catalog → public exporter and numerical sensor controls → P2 linear/reference baseline and static evaluation → only then a causal public-observation surrogate if a concrete gap remains. Dynamic forecasting stays a separate track until its whole trajectory domain and physical clock are qualified. No new architecture, fit, role draw or policy result is authorized by this audit.
