The repair uses an exact rational reduction and outward floating-point conversion when necessary. It propagates the existing estimated quadrature, normalizer and root uncertainties. This certifies the scalar reduction arithmetic, not the accuracy of the underlying numerical integration. Quantile tolerances, prior, noise, observations and physical models remain unchanged.
