# Streaming compatible P2 backend: CPU validation

StreamingTwoLevelP2 evaluates the same original FP64 stable Neo-Hookean P2 operator while bounding quadrature working memory. It uses a shallow geometry copy with one quadrature/check point only during parent construction, which performs no physical energy evaluation. It never mutates the supplied model. Those temporary gradients and weights are deleted immediately.

Physical evaluation uses every actual quadrature point, constructing exact P2 shape gradients directly from reference linear gradients in chunks (default eight). Energy, nodal gradient and all vertex/midpoint J checks are accumulated without a full quadrature-by-element gradient, deformation or cofactor cache. The Newton cache contains only element-local displacement, energy, nodal gradient and minimum J. Full Hessian actions and exact nodal 3x3 blocks recompute the compatible gradients/deformation/cofactors per chunk; all determinant cross terms are retained. The full consistent T10 mass and projected additive coarse preconditioner are inherited unchanged. There is no force clipping, stiffness repair or changed original acceptance tolerance.

Five CPU tests passed. They verify model input preservation and bounded cache structure; finite-strain exact-80-point energy, force, full Hessian action, nodal blocks and diagonal against the monolithic backend with both eight-point and nondivisor thirteen-point chunks; exact mass actions and full-mass linear/static solved-state parity; and explicit rejection of nonpositive J and invalid chunk size. The tests exercise a genuine non-affine displacement field. Constant-material polynomial stable NH is the current scope; logarithmic energy, Gaussian-weighted material/fixture laws and clipped surface contact need their own operators and validation.

No GPU call, new physical dataset case or performance/admission claim is made. A separately frozen GPU Q3 12000-tet old-field parity control must precede fine exact-80-point use. Existing live source/protocol bytes remain unchanged. [Validation protocol](protocol.json), [test receipt](tests.txt).
