# Additive coarse P2 preconditioner prototype

The new TwoLevelP2 class adds a fixed coarse compatible-P2 correction to exact nodal 3x3 block Jacobi. It targets the global bending modes that a nodal preconditioner cannot efficiently remove. It changes only the numerical inverse used by PCG; the full FP64 physical Hessian, stable Neo-Hookean law, consistent mass, force, line search, positive-J check and original stationarity gates are inherited unchanged.

The explicit coarse mesh is 4 x 2 x 2 cells with the same public geometry, material values and full left clamp. Prolongation evaluates each coarse P2 finite-element field at the fine material coordinates using authored-tetrahedron barycentrics and complete ten-node shape weights, without clipping or normalization. Fine and coarse fixed DOFs are projected out. Restriction is the literal transpose. Each mass factor reuses the cached FP64 Cholesky factor of the free coarse rest tangent plus that factor times the full consistent coarse mass. The correction is added to the exact nodal-block inverse, so the preconditioner is SPD on the free subspace. No diagonal shift or eigenvalue projection is used; roundoff symmetry averaging affects only the coarse preconditioner and its defect is recorded.

Four CPU tests pass: nontrivial coarse-to-fine constant/affine reproduction and exact constraint-compatible affine fields; projected prolongation/restriction adjoint identity and additive positive/symmetric response; original full-mass finite-strain linear solve agreement with independently assembled sparse direct solve; and rejection of unsupported boundary semantics. Sparse index invariants are explicitly checked at construction. The earlier harmless default sparse-invariant warning and the final clean receipt are both retained.

There are no GPU benchmarks or new physical equilibria/trajectories from this class. No speedup, spatial/time qualification, contact capability or prediction/inference result is claimed. The ongoing 24/32-mesh case continues using its frozen original block-PCG source. An actual GPU test needs its own frozen scope after device release.
